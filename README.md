# Сириус — сервер

Нужен только Node.js 18+. Зависимостей нет.

## Запуск на своём компьютере
    node server.js
Откройте http://localhost:3000 — это и есть приложение.

## Чтобы общались люди из интернета
Разместите папку на любом хостинге с Node.js (Render, Railway, Fly.io, VPS), команда запуска: `node server.js`.
Люди открывают адрес вашего сайта (нужен https) и регистрируются.

- Данные лежат в папке `data/` (или в `DATA_DIR`). На бесплатных хостингах диск часто стирается при перезапуске: подключите постоянный диск и укажите его в переменной `DATA_DIR`.
- Порт берётся из переменной `PORT`.
- Файл `Сириус.html` можно открыть отдельно: он спросит адрес сервера.

## Восстановление профиля и шифрование
- При регистрации задаётся **облачный пароль** (от 8 символов). Из него в браузере выводятся две независимые части: одна уходит на сервер как «доказательство» (сам пароль на сервер не передаётся), вторая шифрует резервную копию вашего приватного ключа.
- На новом устройстве: «У меня уже есть профиль — восстановить» → @username + облачный пароль. Профиль, ключи и вся переписка вернутся; старые устройства при этом выходят из аккаунта.
- Личные чаты и «Избранное» зашифрованы **сквозным шифрованием** (ECDH P-256 → HKDF → AES-GCM-256), фото/видео/голосовые — тоже. Сервер хранит только шифртекст. Код безопасности для сверки — в меню чата.
- Группы и каналы пока без сквозного шифрования.
- **Забытый облачный пароль восстановить нельзя** — так и устроено сквозное шифрование.

## Магазин ★, подарки, оплата — настройка владельца
Всё задаётся переменными окружения на хостинге (в код ничего не вписывайте):

| Переменная | Что это |
|---|---|
| `OWNER_CARD` | номер вашей карты, на которую переводят оплату |
| `OWNER_NAME` | имя получателя (показывается покупателю) |
| `OWNER_BANK` | банк (необязательно) |
| `PAY_URL` | ссылка на оплату в банке (необязательно); можно использовать `{amount}` и `{order}` |
| `STAR_RUB` | цена 1 ★ в рублях (по умолчанию 1) |
| `MIN_STARS`, `MAX_STARS` | пределы пополнения (10 … 100000) |
| `DEV_CODE` | **код разработчика**, от 8 символов; без него функция выключена |

**Как идёт оплата.** Покупатель: Меню → «Пополнить ★» → вводит количество → видит сумму и реквизиты карты → переводит → нажимает «Я оплатил(а)». Вы: Меню → «Панель владельца» → видите заказ → после проверки поступления нажимаете «Деньги пришли». ★ зачисляются автоматически, а покупателю приходит сообщение от «Сириус Бот». Автоматически проверить перевод на личную карту нельзя — подтверждаете вы вручную.

**Код разработчика.** Меню → «Код разработчика» → код → количество ★. Код проверяется только на сервере, после ввода аккаунт получает права владельца (панель заказов, выдача ★). Неверные попытки ограничены (5 → пауза 15 минут). Все начисления пишутся в журнал `audit` в `db.json`.

**Подарки.** Каталог — массив `GIFTS` в начале блока магазина в `server.js`: цена (`p`) и тираж (`s`). Чем реже подарок, тем меньше тираж и выше цена; когда тираж кончается, подарок распродан для всех. Подарить можно из меню чата («Подарить подарок»), с профиля (🎁) или из магазина по @username. Полученные подарки видны в профиле.
